# Зерно — сайт кофейни-пекарни

Концепт сайта кофейни в тёплом «журнальном» стиле.

## Что есть на сайте

- Первый экран с фото-аркой, вращающимся бейджем и анимацией пара
- Меню с вкладками «Кофе / Выпечка / Завтраки» и плавной сменой фото
- Корзина предзаказа: количество, итоговая сумма, время самовывоза, номер заказа с анимацией чашки
- Квиз «Подбери свой кофе» — 3 вопроса и рекомендация напитка с добавлением в заказ
- Интерактивная карта лояльности: штампы по клику, 7-й кофе в подарок
- Статус «Открыто / Закрыто» по реальному времени и часы работы
- Бегущая строка, параллакс, плавное появление блоков, адаптив под телефон

## Технологии

Чистые HTML, CSS и JavaScript — без фреймворков. Шрифты Playfair Display и Manrope, фото — Unsplash.
