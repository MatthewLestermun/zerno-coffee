# Зерно — сайт кофейни-пекарни

Концепт сайта кофейни в тёмном «шоколадном» стиле: карамельные заголовки, стеклянные карточки, 3D-стаканчики.

## Что есть на сайте

- Первый экран с 3D-стаканчиками «Зерно»: слетевшая крышка, брызги кофе, летающие зёрна, реакция на мышь
- Карточки напитков с 3D-стаканчиками в фирменных цветах, рейтингом и кнопкой «+» в заказ
- Блок «Зерно — это» со стаканчиком, который поворачивается при прокрутке
- Меню с вкладками «Кофе / Выпечка / Завтраки»
- Корзина предзаказа: количество, итоговая сумма, время самовывоза, номер заказа с анимацией чашки
- Квиз «Какой кофе подходит тебе» — 3 вопроса и рекомендация напитка с добавлением в заказ
- Интерактивная карта лояльности: штампы по клику, 7-й кофе в подарок
- Статус «Открыто / Закрыто» по реальному времени и часы работы
- Адаптив под телефон

## Технологии

HTML, CSS и JavaScript, 3D на Three.js. Шрифты Unbounded и Manrope, фото — Unsplash.
